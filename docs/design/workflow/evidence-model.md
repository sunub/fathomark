# 근거·공유 상태의 계약

상태: **설계 초안 · 구현 전**  
기준일: 2026-10-11  
[문서 목차](README.md)

💡 **근거표**: 글에 사용할 주장과 이를 뒷받침하는 구절을 연결한 표다. 확인된 사실, 사용자 보충, 모델 해석과 누락을 구분한다. **출처 계보**는 그 정보가 어디서 왔는지 식별자로 추적하는 기록이다.

| 정보 종류 | 보존할 항목 | 허용 용도 |
|---|---|---|
| 경험 노트 | 노트 ID·위치·원문 구절 | 사용자의 경험에 관한 주장 지원 |
| 사용자 보충 | 실행 ID·질문 ID·답변 ID·원문 답변 | 사용자가 직접 확인한 사실. 노트 인용으로 표시하지 않음 |
| 공개 자료 | URL·제목·구절·수집 시각. 붙여넣은 자료는 URL 없이 자료 ID로 식별하며 이를 담는 형식은 미정 | 회사·직무 요구사항과 배경 설명 |
| 문체 참고 | 문체 규칙·별도 참고 범위 | 표현과 구성 참고. 원본의 역할·수치·사건 복사 금지 |
| 모델 해석·작업 메모 | 관련 출처 ID·해석 표시 | 경험 비교·개요 선택. 새로운 사실로 승격 금지 |

각 실행은 요청과 작성 조건, 현재 단계, 허용 자료, 근거·누락·충돌, 행동 이력·누적 한도, 질문·대기 상태, 초안·주장별 출처, 수정 횟수·검증 결과, 미리보기 버전·대상·승인을 공유한다. 도구 결과는 성공·부분 성공·결과 없음·오류를 구분한다. 일반 설명문을 읽고 상태 전이를 추측하지 않는다.

상태는 요청 정리, 탐색, 사용자 입력 대기, 작성 가능성 확인, 초안, 검증, 미리보기, 승인 대기, 적용, 완료·미완료·취소로 구분한다. 단계와 대기는 같은 축으로 구현할지 별도 상태로 구현할지 후속 계약에서 결정하되, 대기 중 실행이 이어지지 않는 조건은 유지한다.
