실행 한도·대기·검증·승인 정책

상태: 설계 초안 · 구현 전
기준일: 2026-10-11
문서 목차

초기 탐색은 기존 한도의 모델 라운드 8회, 총 도구 호출 12회, 도구별 5회를 출발점으로 검토한다. 실제 사례 평가 후 조정하며 공개 조사 추가 시도도 무제한으로 허용하지 않는다. 질문 횟수·자료 길이·활성 실행 시간의 상한은 구현 전에 수치로 확정한다.

사용자 답변·승인을 기다릴 때 모델·도구 호출과 활성 실행 타이머를 멈춘다. 재개해도 이전 호출 수와 사용량은 유지한다. 대기 중 취소되거나 다른 요청으로 대체된 실행의 늦은 결과는 버린다. 앱 재시작으로 종료된 실행을 자동 복구하거나 승인하지 않는다.

검증은 출처 존재·구절 연결·역할·수치·성과 의미·문체 원본의 사실 혼입을 확인한다. 구조 검사와 의미 검사는 구분한다. 코드로 출처 ID를 확인해도 원문이 주장을 지지한다는 보장은 없으며, 의미 검증 모델도 오류를 낼 수 있다. 최초 초안과 최대 1회의 수정 초안을 각각 검증하고, 통과한 결과만 승인 가능한 미리보기로 제공한다.

초안 제시로 채팅 요청은 완료될 수 있다. 노트 적용은 별도 선택이다. 승인 시 문서·선택 영역·미리보기 버전이 일치하는지 확인하고 변경됐다면 새 미리보기와 승인을 요구한다. 중복 승인으로 같은 내용을 두 번 적용하지 않는다. 기존 적용 기능을 재사용하는 방향이다.
