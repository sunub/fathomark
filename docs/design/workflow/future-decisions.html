후속 검토: Obsidian CLI·실행 프레임워크

상태: 설계 초안 · 구현 전
기준일: 2026-10-11
문서 목차

💡 CLI: 터미널 명령으로 프로그램 기능을 호출하는 방식이다. Obsidian CLI는 실행 중인 Obsidian 앱에 검색·읽기 등의 요청을 전달한다.

공식 CLI 도움말의 검색·문맥 검색·읽기·연결 조회와 공식 API 정의의 CLI 처리기 등록은 후속 비교 후보다. 외부 AI가 Fathomark 기능을 호출하거나 실제 앱 개발·검증을 자동화하는 데 활용할 수 있다. 내부 플러그인 기능을 전면 교체하는 결정은 하지 않았다.

검색 후보 확보를 CLI에 맡기더라도 경험 우선순위·의미 검색·근거 충분성·승인 경계는 별도 책임이다. 동일 Vault와 질문으로 정확도·시간·지원 버전을 비교한 뒤 판단한다. 실행 프레임워크도 아직 선택하지 않았다. 현재 파일에 특정 라이브러리 이름이 있더라도 이번 설계의 채택 결정으로 해석하지 않는다.
