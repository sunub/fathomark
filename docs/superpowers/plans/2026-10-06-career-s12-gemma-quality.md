# S12: 로컬 Gemma 4 한국어 글쓰기 품질 측정

**목표**: 로컬 Gemma 4 변형별로 한국어 지원서 글쓰기 품질을 S1 고정셋으로 측정하고, S10의 하드웨어별 권장표를 측정값으로 확정한다.

**선행**: S1(고정셋), S3(`verifyClaims`), S6(구조화 호출), S10(provider 선택). **프레임워크**: 없음.

## 범위

- 변형(S10 권장표의 E2B, E4B 등)마다 같은 고정셋으로 초안을 생성한다.
- 지표: 근거 없는 주장 비율(S3), 근거 인용 정확도, 한국어 자연스러움(사람 평가 소규모), 응답 시간.
- 결과는 `docs/testing/`에 수치로 남기고, S10 권장표를 갱신한다.

범위 밖: 모델 학습(원칙 1), 외부 모델 비교(외부 provider가 붙은 뒤).

## 파일

- Create: `plugin/tests/support/gemma-quality-run.ts`(수동 실행 스크립트, 기본 `pnpm test`에는 포함하지 않는다), `docs/testing/gemma4-korean-quality.md`
- Modify: `docs/superpowers/plans/2026-10-05-career-s10-provider-selection.md`(권장표의 "미측정" 갱신)

## 작업

- [ ] 사람 평가 기준(3점 척도, 항목 3개 이내)을 문서에 먼저 고정한다.
- [ ] 스크립트가 변형별로 고정셋을 돌려 결과를 JSON으로 저장한다.
- [ ] 측정을 실행하고 수치를 `docs/testing/gemma4-korean-quality.md`에 기록한다.
- [ ] 권장표를 측정값으로 고친다. 기준 미달 변형은 "권장하지 않음"으로 표시한다.
- [ ] 검증 명령 실행 후 커밋한다.

## 완료 기준

- 권장표의 모든 칸이 측정값이거나 "측정 불가(이유)"다.
- 모든 변형이 기준 미달이면 그 사실을 DIRECTION의 확인 항목으로 올린다.

## 리뷰 초점

- 변형 간 비교에서 프롬프트와 고정셋이 완전히 같은가.
- 사람 평가가 한 사람의 취향에 치우치지 않았는가.
