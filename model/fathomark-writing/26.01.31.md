## 미친 [아두이노](https://www.acmicpc.net/problem/8972)

이 문제는 로직과 조건을 고려하여 제대로 풀었지만 오타로 인해서 틀렸던 정말 말도 안되게 바보같이 틀린 문제입니다. 문제의 해결방법은 문제의 조건만 신경써서 구현한다면 크게 어렵지 않은 문제였습니다. 이 문제에서 중요했던 조건은 다음과 같습니다.

- 종수는 **하나의** 로봇을 움직인다.
- 미친 로봇은 **하나 이상**일 수있다.
- 미친 아두이노의 위치를 (r2, s2)라고 했을 때, |r1-r2| + |s1-s2|가 가장 작아지는 방향으로 이동한다.
- 미친 로봇이 한 칸에 한개 이상 있을 경우 **모두** 터지게 된다.
- 미친 아두이노가 종수의 아두이노가 있는 칸으로 이동한 경우에는 게임이 끝난다.
- 종수는 **9가지** 방법으로 움직일 수 있지만 미친 로봇은 **8가지** 방법으로 움직일 수 있다.

위의 조건만 제대로 지키고 시뮬레이션을 풀면 제대로 해결할 수 있는 문제였습니다. 저는 위의 조건을 제대로 지키고 시뮬레이션 코드를 작성했지만 바보같이 오타를 내서 문제를 틀렸습니다.

```js
function validatePosition(x, y) {
    if (x < 1 || x >= R || y < 0 || y >= C) {
      return false;
    }
    return true;
}
```

좌표의 시작은 0인데 바보같이 1로 범위 제한을 작성했습니다.

```js
function calculateDist(r2, s1, r2, s2) {
	return Math.abs(r2 - r2) + Math.abs(s1 - s2);
}
```

`r2 - r2` 는 당연히 0인데 바보같이 `r1` 을 `r2`로 작성하여 문제를 틀리는 바보같은 실수를 했습니다. 요즘들어 이렇게 오타를 내서 문제를 틀리는 경우가 빈번한거 같습니다. 문제를 해결하는 로직을 구상하고 해결하는 것도 중요하지만 오타로 인해서 바보같이 헤매고 틀리는 일은 없게 신경쓰고 타이핑도 연습 좀 해야 할것 같습니다.
