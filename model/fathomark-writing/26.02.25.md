## [구간 곱 구하기 실패](https://www.acmicpc.net/problem/11505)

이 문제에서 해결했어야 하는 방향은 **Segment Tree**를 사용하여 구간의 합을 구해야 하는 코드였습니다. 이 문제의 경우 처음에는 Prefix 곱을 사용하여 정답을 도출하고자 했습니다. 하지만 이 방법이 시간제한에 걸릴 것이라고 예측하고 있었지만 제대로 된 해결 방법을 알 수 없어서 그대로 수행했습니다. 하지만 역시 이 방법은 정답이 아니었습니다.

```js
function build(node, start, end) {
  if (start === end) {
    tree[node] = arr[start];
    return tree[node];
  }

  const mid = math.floor((start + end) / 2);
  const leftsum = build(node * 2, start, mid);
  const rightsum = build(node * 2 + 1, mid + 1, end);
  tree[node] = leftsum + rightsum;
  return tree[node];
}
```

위의 과정을 통해서 segment tree 를 구성하는 과정을 갖는다. 위의 과정은 전체 배열의 길이를 이분화하여 값을 업데이트하고 관리하기 때문에 기존의 탐색 이용인 $O(N)$ 을 $O(logN)$ 으로 개선시켜 탐색 시간을 최적화할 수 있는 방법이기 때문에 탐색 시간을 최적화 시킬 수 있습니다.

```js
function update(node, start, end, index, val) {
  if (start > index || index > end) {
    return;
  }

  if (start === end) {
    tree[node] = val;
    return;
  }

  const mid = Math.floor((start + end) / 2);
  update(node * 2, start, mid, index, val);
  update(node * 2 + 1, mid + 1, end, index, val);

  tree[node] = tree[node * 2] + tree[node * 2 + 1];
}
```

위의 과정을 통해서 특정 index의 값을 업데이트하는 과정을 수행합니다. 이 과정또한 전체 트리를 탐색하는 것이 아닌 트리의 이분된 방식을 통해서 탐색을 수행하여 특정 인덱스를 업데이트하기 때문에 효과적으로 업데이트를 수행할 수 있습니다.

```js
function query(node, start, end, left, right) {
  if (start > left || right > end) {
    return 0;
  }

  if (start <= left && right <= end) {
    return tree[node];
  }

  const mid = Math.floor((start + end) / 2);
  const leftSum = query(node * 2, start, mid, left, right);
  const rightSum = query(node * 2 + 1, mid + 1, end, left, right);
  return leftSum + rightSum;
}
```
