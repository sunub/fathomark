저는 교육자로서 학생들의 피드백을 받고 수업을 발전 시키고 동료들과의 토론을 통해서 협업을 수행한 경험과 개발 과정에서 디자이너로써 그리고 팀장이자 FE 개발자로서 협업을 수행한 경험을 갖고 있습니다.

이러한 경험에서 제가 배운 가장 중요한 것은 의사소통이 원활해야 한다는 것이었습니다. 사소한 문제였고 서로의 의견을 공유하면 손쉽게 해결할 수 있는 문제들을 혼자만의 생각에 갇혀서 오랜시간이 걸리거나 제대로 완성되지 않아 결국 다시 만들어야 하는 문제들을 겪었기 때문입니다.

그래서 저는 이를 해결하기 위해 협업전의 과정이나 요구사항들에 대해서 시각화를 수행하였습니다. 예를들어, User Flow를 설계하여 각 역할에 필요한 기능을 시각적으로 정리하고, 팀원들이 직관적으로 이해할 수 있도록 가이드라인을 제공했습니다. 이를 통해 개발 진행 시 혼선을 줄이고, 원활한 역할 분담을 할 수 있었습니다.

또한 백로그를 기반으로 기능 우선순위를 설정하고, 팀원들과 주 단위 일정 계획을 합의하여 프로젝트의 흐름을 체계적으로 관리했습니다. 그 결과, 일정 지연 없이 프로젝트를 완수할 수 있었습니다.

그리고 개발 과정에서는 공통 계약, 커밋 메시지에 대한 규칙을 자동화하는 환경 설정을 하는 것이 좋다는 것이 중요하다는 것을 배웠습니다. 자동화가 제대로 수행이 되지 않았을 경우 팀원들과의 규칙이 다르기 때문에 코드 품질이 무너지고 작성한 PR 이나 커밋 메시지는 어떠한 작업을 수행했는지 명확하게 알 수 없었기 때문입니다.

그래서 husky 를 사용하여 commit 이나 push 시의 규칙을 강제하여 작업 내용을 다른 팀원들도 이해하기 쉽게 강제하거나 Zod 기반 API 타입 검증 패키지를 제작하고, API 통신 시 반드시 사용하도록 팀원들과 합의하여 API 불일치를 사전에 방지하고 버전 충돌을 줄여 원활한 협업 환경을 구축하는 과정을 수행했습니다.

프론트엔드 협업에서는 코드 리뷰어 역할을 수행했습니다. 코드 리뷰 시 Profiler를 통한 성능 데이터 측정과 AI 기반 시각 자료 비교를 도입해 불필요한 리렌더링과 비효율적 코드 구조를 객관적 데이터로 평가했습니다. 이를 통해 성능 최적화 코드를 유도하여 서비스 성능과 유지보수성을 향상시켰습니다.

이번 경험으로 단순한 개인 기술을 넘어 팀 리딩과 원활한 협업 환경 구축 역량을 키웠습니다. 명확한 커뮤니케이션과 체계적 협업 방식이 프로젝트 성과에 미치는 영향을 체감할 수 있었습니다.

저는 교육자로서 청중과 소통하고, 디자이너로서 시각적 요구사항을 설계하며, FE 개발자이자 팀장으로서 프로젝트를 완수해 낸 다채로운 경험을 갖고 있습니다. 이 과정을 통해 직군 간의 관점 차이로 발생하는 소통의 병목이 프로젝트의 가장 큰 리스크임을 뼈저리게 경험했습니다.

Betting Duck 프로젝트에서 팀장으로 프로젝트를 이끌 당시, 잦은 요구사항 변경과 기획의 변동으로 인해 프론트엔드와 백엔드 간의 통신 규격(Payload)이 지속적으로 어긋나는 문제가 발생했습니다. 기존에는 이를 해결하기 위해 User Flow를 시각화하거나 API 명세서를 꼼꼼히 작성하는 등 '문서와 대화'에 의존했으나, 이는 결국 개발 속도를 늦추고 휴먼 에러를 유발하는 한계가 있었습니다.

저는 이를 단순한 소통의 부재가 아닌, '시스템의 부재'로 판단했습니다. 이를 해결하기 위해 문서 기반의 소통을 폐기하고, 타입스크립트(TypeScript) 기반의 'Shared 모듈(Zod/Schema)'을 도입하여 프론트엔드와 백엔드가 동일한 타입 규격을 물리적으로 공유하도록 아키텍처를 재설계했습니다. 양측의 규격 불일치 에러를 컴파일 타임에 원천 차단하는 PoC(개념 증명) 코드를 직접 작성하여 팀원들을 설득했고, 성공적으로 파이프라인에 도입했습니다.

그 결과, 소모적인 규격 논의 미팅과 런타임 에러가 근절되었고, 지연 없이 프로젝트를 완수할 수 있었습니다. 진정한 협업이란 대화를 많이 하는 것이 아니라, 휴먼 에러가 발생하는 지점을 기술적 시스템으로 방어하여 팀원 모두가 본연의 로직에만 기민하게 몰입할 수 있는 환경을 구축하는 것임을 깨달았습니다. 다양한 직군의 언어를 이해하는 유연함과, 병목을 기술로 돌파하는 결단력으로 스냅덱의 빠른 스프린트에 기여하겠습니다.
