## [중요한 단어를 스포 방지](https://school.programmers.co.kr/learn/courses/30/lessons/468370),  [노란불 신호등](https://school.programmers.co.kr/learn/courses/30/lessons/468371)

이 두 문제는 모두 Brute force 로 해결했어야 하는 문제였습니다. 오랜만에 풀어보는 브루트 포스 문제라서 처음에 조금 헤매었습니다.

이 문제에서 중요한 것은 **확실한 경우**를 잘 찾아야 한다는 것이었습니다. 브루트 포스 문제의 경우 조건을 엄격하게 수행하여 특정 조건에 해당하는 모든 경우를 빠짐없이 찾아야만 합니다. 그렇기 때문에 문제의 조건을 분석하고 모든 경우를 어떻게 효율적으로 탐색할 것인가에 관한 것이 중요한 점입니다.

이 두 문제에서의 핵심은 문제의 입력 값의 범위가 크지 않으니 **배열로 상태를 저장하고 추적한다**는 것이었습니다. 예를 들어 노랄불 신호등 문제를 보겠습니다. 

```js
const colors = Array.from({ length : M }, (_, i) => Array.from({ length : sums[i] }, () => ''));
```

이 문제의 주어지는 범위가  `2 ≤ signals의 길이 = n ≤ 5`이며  `3 ≤ G + Y + R ≤ 20` 이기 떄문에 배열로 값을 추적하기에는 충분한 크기입니다. 그렇기 때문에 문제의 시작 범위부터 끝 지점까지 모두 탐색을 수행하면서 저장되어 있는 배열의 값에 해당하는지를 판단하면 됩니다. 노란불 신호등 문제 또한 마찬가지입니다.

```js
// 1 ≤ `spoiler_ranges`의 길이 ≤ 1,000
const isSpoilerChar = new Array(message.length).fill(false);
```

범위가 작기 때문에 위와 같이 스포일러에 해당하는 범위를 배열로 표시한 후 0의 인덱스부터 시작해서 마지막 배열까지 하나하나 확인을 해가면서 스포일러의 해당하는 단어를 처리해가면 쉽게 해결할 수 있는 문제였습니다.

브루트 포스 문제는 생각을 빠르게 정리하는 것이 중요한것 같습니다. 대부분의 경우 알고리즘을 요구하지 않고 어떻게 효율적으로 탐색을 수행할 것인지가 가장 중요하기 때문에 문제를 풀때 생각을 먼저 끝낸 후에 해결하는 과정을 가져야 합니다.
