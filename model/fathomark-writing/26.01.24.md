## [Gaaaaaaaaaarden](https://www.acmicpc.net/problem/18809)

이 문제에서 저를 가장 어렵게 했던 부분은 **서로 다른 두 좌표 값에서 동시에 확장** 하는 것을 어떻게 시뮬레이션 해야 하는지에 대해서 오랜 시간 헤매었다는 것입니다.

서로 다른 두 좌표를 동시에 시뮬레이션 한다고 하여 여러 상태를 여러개의 큐로 관리해서는 안되었습니다. 다른 좌표를 관리하더라도 하나의 큐를 사용하여 문제를 해결해야 했습니다. 여러개의 좌표의 상황을 하나의 큐에 저장하여 관리하는 것이 작업 시간과 복잡도 측면에서 유리하기 때문에 문제를 최대한 단순하게 만들기 위해서 노력해야 했습니다.

### 상태 관리

이 문제에서 존재하는 상태 값은 다음과 같이 정의할 수 있습니다.

```js
const EMPTY = 0;
const RED = 1;
const GREEN = 2;
const FLOWER = 3;
```

위와 같이 상태를 정의하여 관리하는 것이 문제를 더 단순하고 직관적으로 접근할 수 있게끔 도와주므로 상태 값이 여러가지일 경우는 위와 같이 정의하여 문제를 해결하는 것이 필요합니다.

이 문제에서 조건은 **시간**과 **이동을 시작하는 값의 상태** 값을 고려해야 한다는 조건이 있었습니다. 그렇기 때문에 상태를 관리해야 하는 값도 두 가지로 생각하여 문제를 해결해야 했습니다.

```js
const states = Array.from({ length : N }, () => Array(M).fill(EMPTY));
const times = Array.from({ length : N }, () => Array(M).fill(-1));
```

위와 같이 두 가지 2차 배열을 이용하여 상태 값과 시간을 기록해 나간다면 서로에게 영향을 주지 않으면서도 값을 추적할 수 있게 됩니다. 이외에도 큐에 값을 초기화 할 경우도 중요합니다.

```js
const queue = [];
for(const [x, y] of redStart) {
    states[x][y] = RED;
    times[x][y] = 0;
    queue.push([x, y]);
}

for(const [x, y] of greenStart) {
    states[x][y] = GREEN;
    times[x][y] = 0
    queue.push([x, y]);
}
```

이 문제에서는 `redStart`이 여러가지일 수 있고 `greenStart` 또한 여러가지 좌표가 담겨 있을 수 있기 때문에 위와 같이 초기의 좌표 값을 `states`, `times` 에 기록한 후 시작해야 한다는 것을 잊지 말아야 합니다.

이후 탐색의 양상도 일반적인 탐색과는 다른 양상을 보입니다.

```js
while(head < queue.length) {
      const [cx, cy] = queue[head++];
      const currentTime = times[cx][cy];
      const currentStat = states[cx][cy];

      if(states[cx][cy] === FLOWER) {
        continue;
      }

      for(const [dx, dy] of DIR) {
        const [nx, ny] = [cx + dx, cy + dy];
        if(nx < 0 || nx >= N || ny < 0 || ny >= M) {
          continue;
        }
        if(board[nx][ny] === 0) {
          continue;
        }

        if(states[nx][ny] === EMPTY) {
          states[nx][ny] = currentStat;
          times[nx][ny] = currentTime + 1;
          queue.push([nx, ny]);
        } else if(states[nx][ny] !== currentStat && states[nx][ny] !== FLOWER) {
          if(times[nx][ny] === currentTime + 1) {
            states[nx][ny] = FLOWER;
            flowers += 1;
          }
        }
      }
    }
```


기존에 흔히 사용하는 BFS의 경우 `const queue = [[sx, sy, 0]]` 와 같이 배열 내의 좌표에 대한 정보와 현재까지 탐색한 값에 대한 정보를 값이 관리하였습니다. 

하지만 이제 시간에 대한 정보와 값에 대한 정보를 큐에 좌표를 통한 탐색을 분리하여 관리하기 때문에 특정 시간에 특정 값이 어떤 위치에 있는지에 대한 정보를 이동을 하면서 값을 오염시키지 않고 탐색을 할 수 있게 되었습니다.

- **`states[nx][ny] === EMPTY`**: 빈 땅이므로 내가 **선점**합니다. (큐에 넣음)
- **`else if (... !== currentStat)`**: 누군가 이미 왔는데 나랑 다른 색입니다.
    - **`times[nx][ny] === currentTime + 1`**: 나랑 **도착 시간이 같음** $\to$ **충돌(꽃 생성)**.
    - **`times[nx][ny] < currentTime + 1`**: 상대방이 **먼저 도착해서 자리 잡음** $\to$ 나는 진입 불가 (아무것도 안 함).
